splay - Windows x64 development preview

Full instructions: docs/install.md. Preview 4 test record: docs/validation-v4.md.
Source and downloads: https://github.com/noxowin/splay
Use the source tag corresponding to the downloaded Release; CI builds are previews.

INSTALL / UPGRADE
Close mpv. Copy all four files into its active configuration's scripts folder:
  scripts/splay.lua
  scripts/splay_core.dll
  scripts/splay_overlay.lua
  scripts/splay_playlist.lua
Replace only splay files; keep existing player settings and other scripts.
Requires Windows x64 mpv with C plugins and mp.input. uosc is optional.

USE
Open media normally. Shift+s or the bottom Sync icon opens the menu.
Each new player starts with splay disabled. Enable it, choose a room, then connect.
Defaults: syncplay.pl:8999, nickname splayuser, no default room.
Connected: Enter opens/sends chat, Esc cancels, Shift+h opens session messages.
Server passwords are remembered with Windows current-user encryption; settings
allow deletion or disabling. Password input is visible. Do not share private
configuration, splay-history.json, splay-credentials.json or debug logs.
Shared playlists do not transmit media. Local following is off by default.

UNINSTALL
Close mpv and remove only the four splay files and any splay-only settings.
Optional history/credential cleanup and configuration details: docs/install.md.
