INSTALL / UPGRADE
Check the ZIP SHA256 against the release checksum. Close mpv.
Copy all four files into the active mpv configuration's scripts directory:
  scripts/splay.lua
  scripts/splay_core.dll
  scripts/splay_overlay.lua
  scripts/splay_playlist.lua
Replace only splay files; keep player settings and other scripts.
Requires Windows x64 mpv with C plugins and mp.input. uosc is optional.

USE
Open media normally. Shift+s or the Sync icon opens the menu.
Each new player starts with splay disabled; enable it and connect manually.
Initial server: syncplay.pl:8999; nickname: splayuser; no default room.
Enter opens/sends quick chat; Esc cancels. Shift+h opens transparent message
history with continuous chat; Page Up/Down or wheel scroll, Esc closes.
Settings provides chat mode, visibility, room behavior and reconnect options.
Settings > Language switches Simplified Chinese/English; Auto follows Windows.
Chat mode, language and join/leave pause preferences are remembered with history.
Join pause requests a room-wide pause; a member leaving the same room also
requests a pause. Both default on and obey controlled-room permissions.
All-ready autostart defaults on with a five-second countdown. Use one coordinator
per room. Server RTT display/sharing also defaults on; peers need reporting support.
Smooth catch-up defaults on: 1.5 to 4 s ahead of the room plays at 0.95x until
level instead of jumping back. Turn it off in Settings or with smooth_catchup=no.
Smoother scrolling chat is optional and off by default; it adds playback load.
Duration comparison uses exact reported values, not filenames or content hashes.
Local time offset can be entered or suggested from a member's duration, then
edited and confirmed. It is not saved across processes and resets for new media.
Shared playlists do not transfer media. Local following defaults off. Sharing
network URLs and opening unfamiliar network entries require explicit confirmation.
Passwords are typed into the mpv input box and are visible while typed;
remembered ones are stored encrypted for the current Windows user. Debug-level
mpv logs, including any --log-file, contain typed passwords in plain text.
Do not share private settings, history, credentials or debug logs.

UNINSTALL
Close mpv; remove only the four runtime files and splay-only settings.
Optional history/credential cleanup: see the full installation guide.
