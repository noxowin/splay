# Windows 预览版安装与使用

## 安装到现有 mpv

1. 完全退出要安装插件的播放器。
2. 找到它实际使用的配置目录。常见位置是 `%APPDATA%\mpv` 或 `mpv.exe` 旁的 `portable_config`；整合包可能另行指定路径。
3. 将包内 `scripts/splay.lua` 和 `scripts/splay_core.dll` 复制到该目录的 `scripts` 文件夹。若已有同名文件，先单独备份旧版本。
4. 保留原有 `mpv.conf`、`input.conf`、`uosc.conf` 和其他脚本。可选配置在 `script-opts/splay.conf.example`；按需复制为 `splay.conf`，其中不要保存密码。
5. 按平时的方式打开视频，使用 **Ctrl+Shift+s** 打开面板。键位未强制占用；如果已有冲突，可在自己的 `input.conf` 中为 `script-message-to splay splay-open` 分配其他按键。

宿主需要 Windows x64、mpv C 插件支持及 Lua `mp.input` 输入接口。已验证的具体宿主见 [验证记录](validation.md)，不能据此保证所有旧版本或 mpv.net 均支持。启动器若禁用脚本或指定其他配置目录，需要把插件安装到该实例真正加载的位置。

## 连接和房间

在面板中设置服务器地址、端口、昵称和房间，按需填写服务器密码，然后选择连接。加入时保留当前媒体，只同步播放状态。各成员需要自行打开相同内容、相同时间轴的可跳转视频。

成员面板显示昵称、所在房间、准备状态和操作员身份；准备状态未知时不会被当作未准备。准备状态不自动触发全员开播。

原生面板显示打开时的状态，可选择“刷新状态与成员列表”或重新打开面板；uosc 菜单在打开期间随状态更新。

普通房间内成员可以同步操作。要由房主管理播放，创建或加入 Syncplay 受控房间，再进行操作员认证。新建受控房间的基础名称最多 21 个字符，密码格式为 `AB-123-456`。服务器会返回带前缀和摘要的完整房间名，其他成员使用该完整名称加入；普通成员无法改变房间的全局播放状态。服务器密码与操作员密码用途不同。

主动断开或连接丢失后可继续本地播放。重连需要手动选择，不会在后台无限重试。播放器多个实例各自独立，默认均不连接。

## TLS 和输入

- `prefer`：先协商 TLS；仅服务器明确表示不支持时允许明文，并在面板中显示实际状态。
- `require`：必须加密，不接受明文。
- `off`：主动使用明文。

证书或握手失败不会自动转成明文连接。首版使用 Windows Schannel 的 TLS 1.2 与系统证书信任；证书链检查使用缓存，不主动联网获取缺失证书材料。

密码输入框目前无法遮罩，屏幕上的文字可见。插件不将密码写入配置或日志，但 mpv 输入模块会在当前进程内保留输入历史；清除 splay 的内存密码并不等于清除输入模块的全部历史。退出播放器会结束这个进程。不要把真实密码放进调试命令、终端历史或对外分享的 IPC 日志。

## 可选 uosc

无需 uosc 即可使用原生面板。安装 uosc 后，可通过 `script-message-to splay splay-open uosc` 打开菜单，或在 `splay.conf` 中设置 `ui=uosc`。

插件注册 `splay` 按钮，但不会修改 uosc 配置。希望显示工具栏按钮时，自行将 `button:splay` 合并进 uosc 的 `controls`。已测版本为 5.13.0。

## 使用限制与卸载

非 1x 播放会暂停同步并显示提示；缓冲、加载和跳转期间暂不传播本地操作。不可跳转媒体无法对齐进度。不同剪辑、广告时间轴、直播、平台鉴权资源解析和共享播放列表均不在本版验证范围内。

卸载时退出播放器，仅删除 `scripts/splay.lua`、`scripts/splay_core.dll`，以及你为 splay 创建的配置和按钮/快捷键条目。不要删除整个配置目录或脚本目录。
