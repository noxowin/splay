# Windows 预览版安装与使用

## 安装到现有 mpv

1. 完全退出要安装插件的播放器。
2. 找到它实际使用的配置目录。常见位置是 `%APPDATA%\mpv` 或 `mpv.exe` 旁的 `portable_config`；整合包可能另行指定路径。
3. 将包内 `scripts/splay.lua`、`scripts/splay_core.dll` 和 `scripts/splay_overlay.lua` 复制到该目录的 `scripts` 文件夹。若已有同名文件，先单独备份旧版本。升级时替换全部三个运行文件。
4. 保留原有 `mpv.conf`、`input.conf`、`uosc.conf` 和其他脚本。可选配置在 `script-opts/splay.conf.example`；按需复制为 `splay.conf`，其中不要保存密码。
5. 按平时的方式打开视频，使用 **Shift+s** 打开菜单，或将鼠标移到底部点击同步小图标。菜单第一项启用/关闭 splay。Shift+s 未强制占用；已有 `input.conf` 条目优先。需要明确绑定时添加 `SHIFT+s script-message-to splay splay-open`，希望直接进入 uosc 菜单则在末尾加 `uosc`。mpv 原本的大写 `S` 截图键与此键相同，需自行决定保留哪个动作。

宿主需要 Windows x64、mpv C 插件支持及 Lua `mp.input` 输入接口。已验证的具体宿主见 [本轮验证记录](validation-v3.md)，不能据此保证所有旧版本或 mpv.net 均支持。启动器若禁用脚本或指定其他配置目录，需要把插件安装到该实例真正加载的位置。

## 连接历史与默认值

首次默认服务器为 `syncplay.pl`，端口 `8999`，昵称 `splayuser`，房间留空。连接或新建房间前必须填写或明确选择房间名，不再自动加入 `Default`。旧版历史中的 `Default` 占位值不自动恢复到表单，但仍保留在历史列表中供手动选择。如果旧 `splay.conf` 中有 `room=default`，请删掉该行或改成自己的房间。

填写的服务器、端口、昵称、房间和 TLS 策略会保存到当前 mpv 配置目录的 `splay-history.json`。房间未填时也可保存其他字段作为草稿；完整连接组合必须含有房间。单个字段可以选择历史值或手动输入；点击连接或“保存当前连接组合”会保留完整组合。不同值与组合去重保存，不因更换视频或重启播放器而丢失。同一 mpv 进程换视频保留当前启用状态与连接；新进程恢复表单，但 splay 仍关闭，不自动连接。

“历史连接组合”只填表。填写新房间后，用“切换当前连接到填写房间”在当前连接中换房，或用“连接 / 手动重连”应用整组设置。选择组合会清除内存里的服务器密码，避免带到另一个服务器。

保存的历史优先于 `splay.conf` 中的首次默认值。设置 `history_enabled=no` 可停用历史读取和保存，此时只使用配置默认值。密码和聊天记录不写入历史文件。文件旁的 `.lock` 用于多个播放器同时保存，保留它即可；如保存失败，面板会提示，已有历史不会被覆盖为空。

## 状态文字、聊天与鼠标操作

每次新开播放器，splay 默认关闭，仅保留入口，不显示连接、房间、准备状态或聊天。启用后左上角显示连接状态；连接成功后显示本房间准备状态与房间名：未准备或未知状态为红色，全员准备为绿色；近期暂停、恢复、跳转操作为青色，聊天为白色。播放操作提示约 5 秒后消失；聊天默认显示 12 秒、最多 4 条。关闭 splay 会断开连接并清空会话提示，保留当前媒体和连接历史。

已启用、连接成功且已加载媒体时，按 **Enter** 进入聊天输入，再按 **Enter** 发送，**Esc** 取消；也可从菜单进入聊天。服务器未启用聊天、尚未连接或 splay 关闭时不接管 Enter，因此原有全屏等动作仍可使用。其他输入框或菜单打开时也不接管 Enter。可在设置中查看本房间最近 100 条聊天，切换房间、断开或退出时清空，不保存到磁盘。字符上限由服务器提供，官方 1.7.6 默认 150 字符。

鼠标移到底部，点击同步图标展开小菜单；第一项为开关，其余常用操作按连接状态出现。连接设置、成员、显示设置和房间管理分别展开，首页不再列出所有字段和成员。Esc 或点击菜单外关闭小菜单，进度条仍可操作。

可在显示设置中临时隐藏状态文字或按钮；永久设置使用 `status_osd=no`、`button_enabled=no`。独立图标的 `button_bottom` 默认 48，`button_right` 默认 22，按窗口高度缩放并避让控制条边距；这两个偏移不改变 uosc 内嵌按钮位置。升级时可删除旧版 `button_bottom=85`，使用新默认值。

## 连接和房间

在面板中设置服务器地址、端口、昵称和房间，按需填写服务器密码，然后选择连接。加入时保留当前媒体，只同步播放状态。各成员需要自行打开相同内容、相同时间轴的可跳转视频。

成员面板显示昵称、所在房间、准备状态和操作员身份；准备状态未知时不会被当作未准备。准备状态不自动触发全员开播。

原生面板显示打开时的状态，可选择“刷新状态与成员列表”或重新打开面板；uosc 菜单在打开期间随状态更新。

普通房间内成员可以同步操作。要由房主管理播放，创建或加入 Syncplay 受控房间，再进行操作员认证。新建受控房间的基础名称最多 21 个字符，密码格式为 `AB-123-456`。服务器会返回带前缀和摘要的完整房间名，其他成员使用该完整名称加入；普通成员无法改变房间的全局播放状态。服务器密码与操作员密码用途不同。

主动断开或连接丢失后可继续本地播放。重连需要手动选择，不会在后台无限重试。播放器多个实例各自独立，默认均不连接。

## TLS 和输入

- `prefer`：先协商 TLS；仅服务器明确表示不支持时允许明文，并在面板中显示实际状态。
- `require`：必须加密，不接受明文。
- `off`：主动使用明文。

证书或握手失败不会自动转成明文连接。首版使用 Windows Schannel 的 TLS 1.2 与系统证书信任；证书链检查使用缓存，不主动联网获取缺失证书材料。

密码输入框目前无法遮罩，屏幕上的文字可见。插件不将密码写入配置或日志，但 mpv 输入模块会在当前进程内保留输入历史；清除 splay 的内存密码并不等于清除输入模块的全部历史。退出播放器会结束这个进程。不要把真实密码放进调试命令、终端历史或对外分享的 IPC 日志。

## 可选 uosc

无需 uosc 即可使用原生面板。安装 uosc 后，可通过 `script-message-to splay splay-open uosc` 打开菜单，或在 `splay.conf` 中设置 `ui=uosc`。

能够读取当前 uosc 的 `controls` 配置时，插件在**当前进程**加入 `button:splay`，优先放在速度控制后方的空白处，保留其他按钮，不写入 `uosc.conf`。若已经手动配置了该按钮，不重复添加。图标随 uosc 控制条显示，点击后在附近展开菜单。

无法取得控制条布局、没有 uosc 或布局不可用时，使用独立小图标。仅使用 uosc 内置默认布局、没有 `controls` 配置的安装也会使用独立图标；可以自行将 `button:splay` 合并到 `controls` 指定位置。整合包控制条布局不尽相同，已测配置和限制见验证记录。

## 使用限制与卸载

非 1x 播放会暂停同步并显示提示；缓冲、加载和跳转期间暂不传播本地操作。不可跳转媒体无法对齐进度。不同剪辑、广告时间轴、直播、平台鉴权资源解析和共享播放列表均不在本版验证范围内。

卸载时退出播放器，仅删除 `scripts/splay.lua`、`scripts/splay_core.dll`、`scripts/splay_overlay.lua`，以及你为 splay 创建的配置和按钮/快捷键条目。不再需要历史时可单独删除 `splay-history.json` 和同名 `.lock`。不要删除整个配置目录或脚本目录。
