# 第四轮：状态分区、密码记忆与房间共享列表

需求确认日期：2026-10-15。用户明确要求共享房间播放列表，而非仅显示成员当前文件。

## 实现边界

- 主动取消暂停自动准备；远端播放应用不替用户准备，普通受控成员仍不能控制房间播放。
- 独立当前用户 DPAPI 凭据库按 host/port 加密保存，Lua 只获得保存状态。保存/读取完成后才继续手动连接，请求编号防止过期回复覆盖当前状态。
- 左上短时事件、右上房间成员及当前文件；右栏按既有鼠标隐藏策略收起，暂停保持。显示未知准备状态不伪装为未准备。
- 统一 300 条内存消息记录，Shift+h 打开；菜单首页含服务器和房间，成员移入子菜单，聊天使用相邻图标与 Enter。
- 原生核心负责共享列表协议和受控权限；独立 Lua 模块负责选择、编辑和本机媒体匹配，保证加入/初次快照不换片。
- 跟随默认关闭且换房重置；显式选择或跟随才能加载，远端路径不可直接执行，未知 HTTP(S) 地址逐项确认，EOF 只推进一次。

## 不在范围内

共享视频传输、平台资源解析、跨设备凭据同步、自动重连、全员准备自动开播、官方新版本的已观看标记，以及完整整合包所有第三方脚本适配。

实际执行的命令、测试结果与未覆盖项见 [验证记录](validation-v4.md)。
