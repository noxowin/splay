# Windows v0.2.1 安装与使用

[English](install.md) · **简体中文** · [项目介绍](https://github.com/noxowin/splay/blob/main/README.zh-CN.md)

## 安装或升级

1. 从 [v0.2.1 发布页](https://github.com/noxowin/splay/releases/tag/v0.2.1) 下载 [splay-windows-x64-v0.2.1.zip](https://github.com/noxowin/splay/releases/download/v0.2.1/splay-windows-x64-v0.2.1.zip)，用发布的 SHA256 校验值核对。
2. 退出 mpv，找到实际配置目录。常见位置为 `%APPDATA%\mpv`，便携版通常使用 `mpv.exe` 旁的 `portable_config`；启动器也可能指定其他目录。
3. 将 **四个文件全部**复制到该目录的 `scripts` 文件夹：`splay.lua`、`splay_core.dll`、`splay_overlay.lua`、`splay_playlist.lua`。升级时先备份已有 splay 文件，再一起替换。
4. 保留原有 `mpv.conf`、`input.conf`、`uosc.conf` 和其他脚本。可从 [splay.conf.example](../script-opts/splay.conf.example) 选取非秘密默认值写入 `script-opts/splay.conf`，不要填写密码。

需要 Windows x64 mpv，支持 C 插件及 Lua `mp.input`；uosc 可选。运行无需 Python、LuaSocket 或独立 Syncplay 客户端。测试版本与覆盖范围见 [验证记录](validation-v0.2.1.md)。GitHub 的 Source code ZIP 不含已编译 DLL。

## 连接与菜单

正常打开媒体，按 **Shift+s** 或点击同步图标。每个新播放器进程都默认关闭 splay，启用后需填写房间并手动连接。初始服务器为 `syncplay.pl:8999`、昵称为 `splayuser`、房间为空；各播放器连接独立。

普通房间不存在时按名称建立，已存在则加入。保存组合支持填入、加入、修改、命名与删除；使用组合加入会等待目标服务器凭据读取。连接后提供房间功能、共享播放列表和“设置”；成员和本机时间偏移在房间功能中。

Shift+s 是普通绑定，`input.conf` 可以覆盖。需要明确绑定时使用 `SHIFT+s script-message-to splay splay-open`，末尾加 `uosc` 可使用其菜单。它与 mpv 大写 S 截图键相同，请自行选择保留的动作。

## 聊天与显示

- 已连接且载入媒体时，**Enter** 输入快聊，再按 Enter 发送，Esc 取消；其他菜单和输入框保留自己的按键。
- **Shift+h** 或“设置 → 消息记录”打开视频上的透明全窗口控制台。Enter 发送后保持输入，Page Up/Down 或滚轮翻阅，Esc 关闭。保留本进程最近 300 条聊天、房间与播放事件，不写入磁盘。换房、断开或停用会关闭控制台与输入。
- 设置可切换聊天室与弹幕；每个昵称使用固定颜色，正文为白色；同房成员优先分到色差明显的颜色，左上角状态和消息记录中的昵称也使用同一颜色。开启历史时模式独立于连接组合记忆。弹幕字号默认增加 15%，聊天室字号不变。
- **播放时平滑弹幕默认关闭**。开启后仅弹幕模式添加有独立标签的 fps 滤镜，将视频输出提高到至多 60 fps（低刷新率屏幕按其刷新率）。这是重复帧而非运动插帧，会增加播放负担。关闭时只移除 splay 自己添加且未被外部修改的滤镜；不支持或发生外部修改会提示。
- **界面语言**：简体中文或英文。“设置 → **语言 / Language**”按 自动 → 简体中文 → English 循环切换，立即生效。自动跟随 Windows 显示语言：任何中文变体使用简体中文，其他语言使用英文。`splay.conf` 中的 `language=auto|zh-CN|en` 设定默认值；开启历史时菜单选择与聊天模式一样记忆，并优先于该默认值。密码输入提示和右上房间信息随之切换；消息记录中已有的条目保持记录时的语言。搭配旧版 `splay_core.dll` 时“自动”保持中文且菜单选择不保存，请四个文件一起替换。
- 左上为短时消息，右上为房间和成员。播放时右栏随鼠标闲置及鼠标隐藏设置隐藏，暂停保持显示；设置可隐藏状态、按钮或房间信息。

## 房间暂停与准备

**加入暂停、成员退出暂停默认开启。** 加入房间时请求全房暂停；同房成员退出或切换到其他房间时也请求暂停。受控房间仍遵守操作员权限。两个选项可在设置中分别关闭，独立于连接组合记忆。加入房间保留当前媒体和调用方播放参数。

**全员准备自动开播默认开启。** 至少两位同房成员均已载入媒体、明确准备，本机暂停、可跳转、1× 且没有缓冲时，可以开始 **5 秒倒计时**。受控房间还要求本机已认证操作员。设置可关闭；连接或换房成功时应用当前偏好，不会每次状态刷新重置倒计时。

准备、成员或媒体变化、缓冲、本机播放操作或远端播放会取消倒计时。一个准备阶段只触发一次，手动暂停后不反复开播；撤回后重新准备，或明确重新开启策略，才能再触发。建议同房仅一人协调，不在客户端间选举倒计时主机。同片时长相等不是开播前提。用户主动播放会自动准备，远端播放不会代替准备。

## 时长比较与本机偏移

时长按有效的**原始秒值**比较：相同为绿色，不同为红色，未知或本机参考为灰色。不使用 2.5 秒容差或文件名“疑似同片”判断。只有不同时额外显示差值行；颜色独立于准备状态和延迟，时长相同不能证明内容一致。

房间功能和成员详情提供**本机时间偏移**：输入正负秒数、逐秒微调或清零。本机时间 = 房间时间 + 偏移；本机片头更长通常用正值。调整只跳转本机并取消本机倒计时，不广播房间跳转、不改变时长比较。换媒体清零，同一媒体换房或重连保留，不跨进程保存。

可选择成员，按“本机时长 − 对方时长”预填，修改后确认。该值替换当前偏移，不累加；连接、成员或媒体信息变化会使旧建议失效。片尾差异或多处删减无法用固定偏移解决，应按实际画面对齐或使用相同版本。

偏移超出本机媒体范围时，仅暂停本机并停在片尾之前，保留房间时钟；重置偏移或房间进入可播放片段后恢复跟随。这个边界暂停不会暂停房间，也不会把截断后的进度发给其他成员。

## 共享播放列表与网络媒体

房间列表独立于 mpv 本机队列，收到列表或加入房间不自动换片。普通房间成员和受控房间操作员可编辑、选集；受控房间普通成员只能跟随。

支持添加文件名、绑定本机文件、导入队列、排序和删除。本机文件只共享名称，不共享完整路径。共享当前 HTTP(S) 地址或导入网络队列项目，发送前需明确确认。确认后完整地址会发给房间所有人，请勿误分享私人或含鉴权信息的 URL。显示会隐藏认证信息和查询参数，但实际确认分享的地址是完整的。

本机匹配仅使用已知队列、当前目录或明确绑定，不递归扫描硬盘，也不自动打开远端绝对路径及其他协议。**本机跟随默认关闭**，换房后重置；开启后跟随房间选集，并在片尾推进下一项，也可明确选择本机播放当前房间项。陌生 HTTP(S) 地址在打开前需逐项确认，本机队列中已有的相同地址或本进程已确认地址可复用。

上限为 250 项、合计 10000 个 Unicode 字符，同时遵守服务器 16 KiB 协议行限制（含用户名和编码开销）。列表是否保留由服务器决定；本机绑定仅本进程有效。不传输视频，尚无已观看标记。

## 历史、密码与重连

`splay-history.json` 保存非密码字段、连接组合，以及聊天模式/加入暂停/退出暂停/界面语言偏好。历史管理可删除组合、字段建议或全部非密码历史，不中断连接。清除连接历史不删除单独保存的密码。`history_enabled=no` 关闭历史读写；开启时，已存历史优先于初始默认值。

服务器密码和操作员密码在 mpv 自带的输入框（console）中输入，**输入时明文显示**，输入前请留意屏幕是否会被他人看到。每次输入使用单独的输入历史，之后不能用上方向键调出，也不写入磁盘；密码不写进连接组合。服务器密码按服务器与端口保存到 `splay-credentials.json`，使用当前 Windows 用户的 DPAPI 加密。输入的密码经 Lua 界面和一条 mpv 命令交给原生核心，因此 debug 级别的 mpv 日志会包含它：`--msg-level=all=debug`（或 `trace`）以及**任何 `--log-file`**（默认按 debug 级别记录）都会写下明文密码，不要分享这类日志。没有视频窗口时（例如 `--vo=null`），console 画在终端里，输入的文字在默认级别下也会出现在标准输出。`remember_password=no` 改为仅本进程记忆，保留已有密文文件。凭据不可跨电脑或 Windows 账号迁移。读写、解密失败会提示，不静默使用空密码重试。操作员密码不记忆。不要公开这些文件或私人日志。

自动重连默认开启，仅用于主动发起的连接。临时失败后依次等待 2、5、10、30、30 秒，最多五次；断开、关闭或取消会停止。密码/协议拒绝、证书失败不重试或降级 TLS。恢复连接保留媒体与参数，不恢复操作员授权、准备状态或列表跟随权限；新进程不会自动连接。

延迟显示与共享默认开启（`latency_enabled=yes`）。数值为各客户端到服务器的往返耗时，不是成员间直连延迟；对方需支持元数据上报，未上报隐藏信号图标，旧值可能标为过期。连接后约每十秒共享，不发送 IP 或媒体 URL；无媒体时可能没有可附带的文件元数据。设置可关闭共享。重连、自动开播、延迟和显示默认值可写入 `splay.conf`；这些菜单修改只在当前进程有效，聊天/加入暂停/退出暂停/界面语言则单独持久记忆。

## 受控房间、TLS 和 uosc

需要限制播放与列表编辑时，创建或加入 Syncplay 受控房间并认证操作员。基础房间名最多 21 字符，操作员密码格式为 `AB-123-456`；其他成员用服务器返回的完整受控房间名加入。服务器密码和操作员密码均在 mpv 输入框中输入，输入时可见。

**平滑追赶默认开启**：本机领先房间 1.5 至 4 秒时，暂时以 0.95 倍速播放直到追平，不再跳回；领先超过 4 秒或落后超过 1.5 秒仍直接跳转。开始和结束都有短暂提示，可在“设置 → 平滑追赶”关闭，或在 `splay.conf` 写 `smooth_catchup=no`。减速期间退出 mpv 不会把 0.95 倍速记入稍后观看。你自己设置的非 1× 播放会暂停同步，splay 不会改动它；加载、缓冲期间不把操作当作主动动作广播。不可跳转媒体无法对齐。浏览器鉴权链、直播和广告时间轴的覆盖有限，见 [验证记录](validation-v0.2.1.md)。

TLS `prefer` 仅在服务器明确不支持 TLS 时允许明文；`require` 拒绝明文；`off` 关闭 TLS。握手或证书失败不降级。当前使用 Windows Schannel TLS 1.2 并拒绝弱加密算法，采用系统信任与缓存证书链检查。

原生 mpv 菜单可独立于 uosc 工作。设置 `ui=uosc`，或发送 `script-message-to splay splay-open uosc`。有可读取的 controls 布局时，在本进程加入 `button:splay` 和连接后的聊天按钮，保留其他按钮，不写 `uosc.conf`；否则使用独立图标。

## 卸载

关闭播放器，仅删除四个运行文件及自行添加的 splay 配置、快捷键和按钮条目。可另删 `splay-history.json`、`splay-credentials.json` 及各自 `.lock` 文件。保留其他播放器配置。
