# splay

为 mpv 增加可选的 Syncplay 同步功能。在浏览器或其他软件打开视频后，直接在当前播放器中连接服务器、加入房间并选择是否同步。

**当前状态：Windows x64 开发预览版。已有原生 DLL、中文面板与可选 uosc 菜单；兼容范围和实际测试结果见 [验证记录](docs/validation.md)。**

首版面向 Windows，以独立插件形式接入用户现有的 mpv 或 mpv 整合包；后续再维护包含同一插件的集成版播放器。仓库先保持私有，初版可用后再准备公开发布。

## 使用流程

1. 用原有方式打开视频，例如浏览器调用外部 mpv。
2. 在播放器内打开 splay 面板，填写服务器、昵称和房间。
3. 查看成员和准备状态，按需加入同步。
4. 同步播放、暂停、跳转；受控房间由操作员控制播放。
5. 退出同步后继续独立播放当前视频。

插件默认不自动连接服务器。媒体仍由各成员自己的播放器获取，Syncplay 仅同步播放状态，不传输视频。

## 已实现的功能

- 兼容现有 Syncplay 服务器，并与官方客户端互通。
- 连接、断开、切换房间，以及明确的连接状态与错误提示。
- 成员列表、准备状态、受控房间及操作员认证。
- 播放、暂停、跳转、进度纠偏与手动重连。
- 无 uosc 时提供独立入口；安装 uosc 后可使用其菜单和可选按钮。
- 保留已有播放器配置、当前媒体和平台传入的播放参数。

聊天、共享播放列表、自动获取他人媒体和自动重连不在本版范围内。准备状态用于查看与切换，不自动实现“全员准备后开播”。

## 安装

关闭播放器，将预览包中的 `scripts/splay.lua` 与 `scripts/splay_core.dll` 放入该播放器实际使用的配置目录下的 `scripts` 文件夹。便携版通常使用 `mpv.exe` 旁的 `portable_config`；不要覆盖其他配置。

正常打开视频，按 **Ctrl+Shift+s** 进入面板，设置服务器、端口、昵称和房间，再选择连接。默认不联网；关闭同步后继续本地播放。密码仅保留在进程内存，输入时屏幕可见。

完整步骤、uosc 按钮与卸载方式见 [安装说明](docs/install.md)。运行插件不需要安装 Python、Syncplay 客户端或 LuaSocket。

## 从源码构建

开发需要 Windows x64、Python 3 与 MinGW-w64 GCC（本次使用 GCC 14.2.0）。在项目目录执行：

```powershell
python tools/build.py package --compiler 'C:\path\to\g++.exe'
```

输出为 `dist/splay-windows-x64-preview.zip`。源码内固定了 JSON 与 mpv API 头文件；构建不下载依赖。官方客户端、播放器和测试媒体仅用于开发验证，不随插件打包。

## 兼容范围

“通用插件”指不依赖某一个 mpv 整合包或启动器。插件仍须被目标 mpv 实例加载，并获得必要接口。禁用脚本、使用另一配置目录、架构不匹配或内嵌 libmpv 的软件需要单独核实。

网络点播首版以各自打开的、可跳转且时间轴一致的媒体为验证对象。浏览器的登录信息、临时链接和请求头不会因为加入房间而自动转移给其他成员。

已测宿主来自 mpv v0.41.0 的 Windows x64 发布资源，二进制实际报告 `v0.41.0-dev-g41f6a6450`；uosc 为 5.13.0，协议互通基线为 Syncplay 1.7.6。尚未测试你实际使用的整合包和浏览器调用链，也未确定最低兼容版本。非 1x 播放暂停同步；不可跳转流只具备有限同步能力。预览版继续保留在私有仓库。
